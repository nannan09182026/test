## 一、技术栈与文件结构
-    使用     **纯原生     HTML     +     CSS     +     JavaScript（ES6+）**
开发，最终打包成**单个可直接运行的  index.html  文件**（所有   CSS   和   JS
内联）。
- 图表库使用 **ECharts CDN**（用于主界面的“曲线分析”功能）。
- 图标使用 **Font Awesome CDN** 或 Unicode 符号。
- 所有数据使用 **localStorage** 进行本地持久化存储，刷新页面数据不丢失。
-   页面采用   **移动端优先（Mobile   First）**   的响应式设计，在手机（宽度
375px~428px）上呈现卡片式 APP 风格，在 PC 上自动居中并适当放大。

## 三、页面与功能模块（严格按说明书）

### 1. 登录页
- 输入用户名、密码，下拉选择角色（普通用户 / 管理员）。
- 点击登录后校验账号密码，跳转至主界面。
- 若管理员登录，底部导航栏多出“系统设置”入口。

### 2. 主界面（首页）
- 顶部显示系统标题和当前用户角色。
-
中间区域以卡片网格展示所有设备（设备编号、名称、实时温度、状态正常/报警）。
-                           **点击单个设备卡片**                           →
跳转至“设备详情页”（显示该设备完整参数和历史报警次数）。
-  **点击设备卡片上的“曲线分析”按钮**  →  跳转至“曲线分析页”（使用   ECharts
折线图展示该设备最近 24 小时的温度变化趋势）。

### 3. 系统设置（仅管理员可见）
- 页面包含两个子项入口：
                                                                           -
**图标说明**：以列表形式展示各状态图标的含义（如绿色正常、红色报警、������离线等
）。
                                                                           -
**系统信息**：显示系统版本号（V2.0）、设备总数、报警总数、运行时长等静态或计
算信息。

### 4. 报警记录
- 列表形式展示所有报警记录（字段：报警时间、设备名称、报警类型、状态）。
- 点击单条记录上的 **“查看详情”** → 弹窗或跳转详情页，显示完整报警信息。
- 每条记录右侧有 **“删除”** 按钮，点击后弹窗二次确认，删除该条记录。
- 页面底部有 **“清空所有记录”** 按钮，点击后弹窗二次确认，清空全部记录。

### 5. 设备设置（仅管理员可见）
- 列表展示所有已添加设备。
-            顶部有            **“新增设备”**             按钮             →
弹出表单（设备编号、名称、位置、类型），提交后添加到列表。
-                        每个设备项右侧有                         **“删除”**
按钮，点击后弹窗二次确认（需校验当前登录用户是否为管理员，若不是则提示无权限
）。

### 6. 账号管理（仅管理员可见）
- 列表展示所有账号（用户名、角色）。
-            顶部有            **“新增账号”**             按钮             →
弹出表单（用户名、密码、角色），提交后添加到列表。
-                        每个账号项右侧有                         **“删除”**
按钮（点击账号图标后出现删除选项），点击后弹窗二次确认。

### 7. 无线测温界面
- 独立底部导航 Tab，展示所有无线测温设备列表。
- 顶部有 **“添加设备”** 按钮 → 弹出表单，输入设备信息后添加。
- **点击单个测温设备** → 进入“设备详情页”，展示该设备下的所有测温点列表。
-         在设备详情页内有         **“添加测温点”**          按钮          →
弹出表单（测温点名称、位置、阈值），提交后添加到该设备下。

## 四、界面交互与 UI 规范
-  采用  **单页应用（SPA）**  模式，所有页面切换通过  JavaScript  控制   div
的显示/隐藏（无需路由库）。
- 顶部导航栏：左侧为返回按钮（除首页外），中间为当前页面标题。
-
底部导航栏（Tab）：固定于底部，包含“首页”、“报警记录”、“无线测温”、“我的/设置
”（管理员登录后显示“系统设置”入口）。
- 所有删除、清空操作必须使用 `confirm()` 或自定义弹窗二次确认。
- 表单提交时需做非空校验，若为空则提示用户。
